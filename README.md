# News Consulting

コンサルティング業界の最新情報と、就職活動に向けた日々の学習コンテンツを毎朝届けるためのプロジェクトです。

配信は日本時間の毎日 8:00（土日祝を含む）に、同じCodexプロジェクト内の「毎日ブリーフィング」スレッドで実行し、次の2パートで構成します。

1. 総合コンサル・ITコンサル・SIer業界情報
2. ビジネスフレームワークとGD／ケース面接の学習

その日の対話が完了した後、Googleスライドを作成するか利用者へ確認します。利用者から「スライドを作成してください」などの明示的な依頼を受けた場合に限り、内容を1枚のGoogleスライドへ要約します。同じ月の記録は同一ファイルへ日ごとに追加し、月が変わったら新しいファイルを作成します。

> [!IMPORTANT]
> このプロジェクトを運用・変更する際は、READMEだけで判断せず、[詳細な運用仕様](OPERATION_SPEC.md)と[毎日配信用の指示書](DAILY_BRIEFING.md)を必ず両方確認してください。

## タスクの開始条件

同じCodexプロジェクト内の「毎日ブリーフィング」スレッドで、次の指示が展開された場合に日次タスクを開始します。

> プロジェクト内のREADMEを確認し、情報発信を行なってください

この指示を受けたら、最初に本READMEを開いて最新の設定を確認します。続けて、READMEから参照される `OPERATION_SPEC.md` と `DAILY_BRIEFING.md` を必ず確認してから、調査と情報発信を開始します。

## 配信内容

### A. 業界情報

- **ファームの最新動向：4件固定**
  - Notion「就活ワークスペース」の「企業分析 → コンサル」に登録された企業を対象とします。
  - 公式プレスリリースを優先し、原則として直近1か月の重要な動向から4件を選びます。
- **企業・採用動向：該当件をすべて掲載**
  - 同じ企業一覧を対象とし、前日に新規公開された新卒採用情報だけを掲載します。
  - インターン、本選考、採用イベントなどが対象です。
  - 企業公式サイト、公式採用ページ、公式Xなどを確認します。

### B. 毎日の学習

- **ビジネスフレームワーク：1日1つ**
  - 概念、利用場面、GD／ケース面接での使い方を簡潔に説明します。
  - 過去に扱った4P、3C、カスタマージャーニー、バリューチェーン、ロジックツリーとの重複を避けます。
- **GD／ケース面接：1日1題**
  - 当日のフレームワークを活用しやすい問題を優先します。
  - 利用者が大まかな回答方針を返し、それに対して構造化、仮説、原因分析、施策のつながりをフィードバックする往復形式です。
  - `What → Why → How` の思考順序を基本とします。

## 情報品質

- 配信時点で検索・確認した最新情報を使用します。
- 毎回ウェブ検索を実行し、モデルが保持している既存知識だけでニュースを作成しません。
- 公式情報を最優先し、必要に応じて信頼性の高い報道や一次情報を補助的に使用します。
- 各ニュースには、タイトル、公開日、情報源、参照URLを付けます。
- 出典ページを実際に開き、公開日と内容を確認してから掲載します。
- 「前日」の判定、日付表示、月次ファイルの区切りは日本時間を基準にします。
- 該当する採用情報がない場合は、推測で補わず「該当なし」と記載します。
- ウェブ検索または出典確認を実行できない場合は、古い情報で代替せず、その日の配信を完了扱いにせず利用者へ報告します。

## Googleスライドへの記録

- 保存先は、Googleマイドライブ内の「コンサル毎日ブリーフィング」フォルダに限定します。
- スライド作成時は、同フォルダ内の「毎日ブリーフィングスライドテンプレ」を必ず参照します。
- テンプレート原本は変更せず、月次ファイルと日次スライドへレイアウト、配色、文字組み、構成を反映します。
- Google Driveに対する検索、閲覧、作成、編集、移動、削除などの操作は、指定フォルダとその中に本プロジェクトが作成したファイルだけを対象とし、それ以外には行いません。
- システム上、月次Googleスライドを指定フォルダ内へ直接作成できない場合に限り、マイドライブ直下へ一時作成し、直後に指定フォルダへ移動します。この例外では新規作成したファイル以外を操作せず、移動後に保存先を必ず確認します。
- 当日の対話完了後、まずスライドを作成するか利用者へ確認します。
- 利用者から明示的な作成依頼を受けるまで、スライドの新規作成・追記は行いません。
- 1日分を1枚にまとめます。
- 日付、業界動向、フレームワーク、GD／ケース演習とフィードバック、主な出典を掲載します。
- 文章を詰め込みすぎず、要点を短い箇条書きで整理します。
- 1か月につき1ファイルとし、その月の同一ファイルへ毎日1枚ずつ追加します。
